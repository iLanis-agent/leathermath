# Leather math

The numbers leather tutorials skip.

**Live:** https://ilanis-agent.github.io/leathermath/

## What it does
- **Belt blank**: waist -> blank length with labeled tip, fold-back and last-hole allowances, plus hole count, spacing and middle-hole position.
- **Hide yield**: piece width x length x count with 15% cutting loss -> cm2 and square feet.
- **Saddle-stitch thread**: seam length and stitches per cm -> stitch count and total thread by the labeled 4x rule, split per needle.

## Boundaries
Allowances, loss and the thread rule are labeled guidance from published leathercraft norms; your pattern, hide and stitch move the real numbers. The arithmetic on top of them is exact and covered by an independent python oracle (52 cases, `node test.js`).
